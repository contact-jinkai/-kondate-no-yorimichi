# 献立のよりみち

1週間の献立・作り方・買い物チェックをまとめたWebアプリの試用版です。

## できること
- 人数と日数の変更、登録済み献立の差し替え
- 主菜・副菜のレシピと並行調理の手順表示
- 買い物リストの集計、購入チェック・取り消し
- ホーム画面用アイコンとWebアプリ設定

## 現在の範囲
AIによる献立自動生成、残量の自動計算、端末間同期は未対応です。
食材・購入チェックはブラウザ内のlocalStorageに保存します。ソースには利用者の入力データ・APIキーは含めません。
副菜は耐熱容器でのレンジ調理を案内しています。

## 配置
ビルド不要。index.htmlと画像、manifest.webmanifestを同じディレクトリで配信します。サブディレクトリへの配置にも対応。
公開範囲を決めてからホスティングを設定してください。GitHub Pagesの公開範囲はリポジトリの公開範囲と別に確認が必要です。
